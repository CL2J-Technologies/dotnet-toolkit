# Entities and attributes

A table is a class. The library reads it with reflection once per process and provider, and caches the
description.

```cs
using cl2j.Database.DataAnnotations;

[Table("Sample", Schema = "dbo")]
public class Sample
{
    [Column(Name = "Id", Key = KeyType.AutoGeneratedKey, Length = 36, KeyPrefix = "smp_")]
    public string Id { get; set; } = null!;

    [Column(Name = "Name", Length = 100, Required = true)]
    public string Name { get; set; } = null!;

    [Column(Name = "Note", Length = 500)]            // optional: Required is false
    public string? Note { get; set; }

    [Column(Name = "Price", Length = 18, Decimals = 2)]
    public decimal Price { get; set; }

    [Column(Name = "CreatedAt")]
    public DateTimeOffset CreatedAt { get; set; }

    [Column(Name = "Tags", Json = true)]             // serialized to a varchar(max) column
    public List<string> Tags { get; set; } = [];

    [Ignore]
    public string DisplayName => Name.ToUpperInvariant();
}
```

## Attributes

| Attribute | Properties |
|---|---|
| `[Table(name)]` | `Name`, `Schema`. Without the attribute the table name is the class name. The schema is optional; see [Schema](schema.md). |
| `[Column]` | `Name`, `TypeName`, `Length`, `Decimals`, `Key`, `Required`, `Json`, `Default`, `KeyPrefix` |
| `[ForeignKey(name, referenceTable, referenceField, referenceSchema)]` | A constraint emitted by `CreateTable`. `referenceSchema` is optional. See [Schema](schema.md#foreign-keys). |
| `[Ignore]` | The property is not a column. |

`[Column]` properties:

| Property | Meaning |
|---|---|
| `Name` | The column name. Defaults to the property name. |
| `TypeName` | A raw provider type (`"nvarchar(100)"`, `"money"`, ...). It replaces the mapping. See [Type mapping](type-mapping.md). |
| `Length` | `string`: the `varchar` length (none means `max`). `byte[]`: the `varbinary` length. `decimal`: the precision, **required**. `Json`: a bound on the text column. |
| `Decimals` | The scale of a `decimal`. |
| `Key` | A [`KeyType`](keys.md). |
| `Required` | `NOT NULL` in the DDL, and a strict read: a `NULL` in a required column throws. |
| `Json` | The property is serialized as JSON text. See [JSON columns](json-columns.md). |
| `Default` | A raw SQL expression appended to the DDL as `DEFAULT <value>`. See [Edge cases](edge-cases.md#default-is-ddl-only). |
| `KeyPrefix` | The prefix of a generated string key. |

## Rules for an entity

- **A public class**, with a public parameterless constructor. A public nested class works; an
  `internal` one is refused (`Type X must be public`).
- **Properties, not fields.** Only public instance properties with a getter are columns, inherited ones
  included. A field carrying `[Column]` is not mapped.
- **Every mapped property needs a public setter** (`init` works). The mapper builds the object with an
  object initializer, so a get-only property that is not marked `[Ignore]` makes the first read throw a
  `DatabaseException` that names the type and the property (`X.Y has no public setter ... Mark it [Ignore] ... or give
  it a setter`); before 6.6.0 it was a Roslyn compile error (`CS0200`). `Insert` still writes such a property.
  Put `[Ignore]` on computed or get-only properties.
- **Column order follows the property order** of the type, and the `SELECT` the library builds lists the
  columns by name.
- **Nullability comes from `Required`, not from C#.** `int Count` without `Required` is a nullable `int`
  column; a `NULL` reads back as `0`. Add `Required = true` to get `NOT NULL`. Enums are the exception:
  a non-nullable enum property is always declared `NOT NULL`; `Kind?` gives a nullable `int` column.
  See [Type mapping](type-mapping.md).
- **A key is found by convention if you declare none:** a property named `Id` becomes a
  `KeyType.Key`. See [Keys](keys.md).

## Mapping to columns the library did not create

Any class can be a read model: raw SQL can select from any table or view, and columns are matched **by
name**, not by position (extra columns in the result are ignored; a column the class needs but the `SELECT`
leaves out fails with an error that names it). The column type has to be the property's own type: see
[Type mapping](type-mapping.md#reading-tables-the-library-did-not-create). See also [Queries](queries.md).
